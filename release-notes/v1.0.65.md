## Highlights
- Cleaner Movies & TV share URLs, more reliable movie runtime display, cleaner Picture-in-Picture dismissal, and sequential Laterbox Assistant actions.

## What's Improved
- Sharing & Deep Links: Updated Movies & TV share links to use cleaner, provider-neutral URLs while preserving full backward compatibility for previously shared links.
- Movies & TV & Durations: Standardized duration formatting (`Xh Ym` / `Xm`), placed movie runtimes cleanly beside the title on detail pages, removed redundant durations from browse cards, and improved automatic runtime enrichment for catalogue movies.
- Laterbox Assistant: Executed queued assistant actions sequentially so multi-step navigation and playback requests finish cleanly in order and report accurate outcomes back to the assistant.

## Bug Fixes
- Fixed Picture-in-Picture window dismissal leaving a stale mini-player bar or out-of-sync playback session state.
- Fixed edge cases in deep-link URL resolution and missing movie runtime metadata.
