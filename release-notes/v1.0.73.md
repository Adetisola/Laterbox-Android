## Highlights
- Restored Movies & TV trailer availability, runtime metadata, automatic DNS-over-HTTPS fallback, and resilient streaming failover across available sources.

## What's Improved
- Added automatic DNS-over-HTTPS fallback for video playback, downloads, thumbnails, and catalogue requests when mobile carrier DNS cannot resolve streaming hosts.
- Expanded guest authentication fallback coverage and tightened request timeouts for faster catalogue loading.
- Added automatic playback failover across alternate stream qualities and formats before surfacing an error.
- Added clearer rate-limit messaging when upstream streaming servers are temporarily busy, with fresh stream resolution on Retry.

## Bug Fixes
- Fixed downloads and streams failing with host-resolution errors on restricted mobile networks.
- Fixed missing Watch Trailer buttons across detail pages and cached titles.
- Fixed missing movie runtimes and image placeholders caused by formatted duration strings and snake-case blur hashes.
- Preserved creator links across cached title details.
