## Highlights
- Improves adaptive stream failover and adds exportable media network diagnostics to pinpoint playback and download request behavior on physical devices.

## What's Improved
- Stream Credential Recovery: Adaptive streams authenticated via signed cookies now retry cleanly after a link refresh when updated credentials are issued on the same manifest address, and expired authorization failures switch faster without unnecessary retry delays.
- Real-Transport Network Diagnostics: Media Downloads settings diagnostics now record request hostnames, Range and Content-Range metadata, HTTP status and redirect chains, cookie presence and expiry status, stream refresh attempts, and final failure categories across playback, downloads, and subtitles with a Share option.

## Bug Fixes
- Preserves exact adaptive manifest paths and prevents download and subtitle redirects from forwarding stream-scoped credentials to unrelated hosts.
- Fixes media playback session cookies potentially being overwritten during header construction.
