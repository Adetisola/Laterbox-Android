## Highlights
- Delivers faster app launch, smoother scrolling across Movies & TV, and quicker title detail and subtitle loading across the board.

## What's Improved
- Faster App Launch: Streamlines startup initialization and splash transition timing so Laterbox opens to your library and feeds sooner.
- Smoother Feeds & Lower Memory Use: Optimizes home feeds, catalogues, watchlist grids, and artwork decoding to reduce frame drops and memory pressure on entry-level devices.
- Quicker Detail Pages & Subtitles: Adds smarter response caching, connection reuse, compressed network payloads, and parallel subtitle fetching for faster playback preparation.

## Bug Fixes
- Improves local watch history lookup speed with upgraded database indexes that preserve existing user libraries cleanly.
- Eliminates unnecessary UI state re-allocations during startup preference loading.
- Restores reliable Inbox media resolution and downloads for X and Instagram links with clean browser fallback when media is unavailable.
- Spotify support is experimental and depends on a third-party service.
