## Highlights
- Improved streaming and download resilience under temporary server rate limits, reduced background TV episode requests, and fixed search typing and suggestion issues.

## What's Improved
- Smarter Streaming Rate-Limit Recovery: When a streaming server temporarily throttles requests, the player places that server on cooldown, switches to alternate available sources, honors retry timing, and performs a controlled link refresh.
- Cleaner Download Retries: Downloads respect server retry windows, switch away from throttled hosts when refreshing links, preserve partial progress, and reschedule long cooldowns cleanly.
- Lighter TV Series Loading: Episode file sizes are now resolved only when opening download options instead of eagerly loading when viewing a TV series page.

## Bug Fixes
- Fixed search suggestions occasionally collapsing to a single keyword item instead of showing all available suggestions.
- Fixed Space and Backspace keys intermittently reverting or dropping while typing quickly in search fields.
- Removed unnecessary burst requests when viewing TV seasons without precomputed episode sizes.
