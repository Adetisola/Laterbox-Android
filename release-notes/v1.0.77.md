## Highlights
- Adds direct on-device stream resolution with automatic service fallback and expanded media diagnostics to improve playback and download reliability.

## What's Improved
- Stream Delivery Route: Resolves direct progressive and adaptive playback links on-device before falling back to the catalogue service, using streamlined request headers compatible with direct video delivery hosts.
- Media Diagnostics: Media Downloads settings diagnostics now include sanitized native resolution outcomes (service host, HTTP status, returned delivery hostnames, and fallback triggers) alongside transport request logs.

## Bug Fixes
- Avoids attaching unnecessary web origin or referrer headers to cookieless direct video streams during playback and downloads.
- Preserves automatic fallback when direct resolution is unavailable in a region or returns a notice clip instead of playable media.
