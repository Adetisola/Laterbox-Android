## Highlights
- Expands on-device stream diagnostics to probe secondary native resource listings and perform a bounded byte-range check while keeping normal playback fallback intact.

## What's Improved
- Stream Client Alignment: Updates the on-device stream resolver client metadata and playback mode flags to match the desktop-free mobile runtime profile accurately.
- Resource & Byte-Range Diagnostics: When direct stream info returns only a notice clip, Media Downloads diagnostics now capture sanitized resource lookup outcomes and a bounded first-kilobyte range verification check (delivery host, path shape, HTTP status, Content-Range, redirect destination, and cookie requirement) without downloading full media files or exposing query tokens.

## Bug Fixes
- Preserves seamless catalogue service fallback during playback whenever direct on-device checks remain diagnostic-only or return only notice clips.
