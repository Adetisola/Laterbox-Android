## Highlights
- Faster live configuration updates across screens, combined trending and custom Movies & TV spotlight banners, stronger version compatibility safeguards, and streamlined built-in analytics.

## What's Improved
- Movies & TV Hero Carousel: Custom spotlight banners configured by administrators now appear alongside default trending movies and series in the same rotating carousel at the configured rotation speed.
- Faster Configuration Sync: Laterbox refreshes live configuration more promptly on startup, when returning to the foreground, and at regular foreground intervals so service notices and layout updates appear within moments.
- Built-In Product & Reliability Analytics: Standardized analytics collection across installations using pseudonymous identifiers, with transparent disclosure and local identifier rotation preserved under Privacy & Data Rights.

## Bug Fixes
- Fixed custom Movies & TV spotlight slides replacing default trending catalogue banners instead of appending to the carousel.
- Fixed an issue where unsupported app build checks could surface as authentication errors instead of clear update prompts.
- Improved version check reliability so temporary network responses from unrelated endpoints never dismiss an active required-update prompt prematurely.
- Fixed analytics heartbeat recovery and offline queue cleanup when global collection is paused and later resumed.
